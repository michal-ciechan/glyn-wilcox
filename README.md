# Glyn Wilcox: website concepts

Six static website samples for Glyn Wilcox: ska singer (The Simmertones), vinyl DJ (Ska Au Go Go) and Palm Torbay radio presenter.

- `index.html`: gallery linking all nine samples
- `simmertones/<concept>/index.html`: three band-site concepts for The Simmertones (brief in `simmertones/CONCEPTS.md`)
- `samples/<concept>/index.html`: each sample, self-contained (inline CSS/JS, Google Fonts, its own `assets/`)
- `CONCEPTS.md`: the design brief for each concept
- `reference/`: research facts, copy deck and source images

No build step. Open `index.html` locally, or publish with GitHub Pages (Settings → Pages → deploy from branch `main`, folder `/`).
